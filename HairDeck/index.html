THE IDEA

A hairstyle is a set.
Generate it as one.

HairDeck turns a single image into stylized hair cards and the spring-bone chains that animate them.

Each card becomes one token. A set diffusion transformer generates all cards together, preserving the individual ribbons that make up a hairstyle. The resulting asset carries per-card UVs and spring bones, and can be exported as a VRM avatar.

Read the abstract +

The hair of stylized characters in games and avatars is built from hair cards: artist-placed ribbons whose geometry is the visible hair, animated by spring bones. Existing image-based methods produce realistic hair or a single fused mesh, while CHARM, the only generator of stylized hair cards, decodes a hairstyle autoregressively as a long sequence of control points.

Observing that a card hairstyle is an unordered set of artist-defined primitives, we propose HairDeck, which generates it as one: each card is a single token, and a set diffusion transformer denoises all cards together. From a single image, HairDeck generates the cards and the spring-bone chains that drive them, yielding an animatable asset that exports to ready-to-use downstream formats.

On CHARM’s own test set, it lowers Chamfer distance by 44% and card-orientation error by more than half while running 33 times faster, and from single images it outperforms CHARM, image-to-3D pipelines and strand-based methods.

METHOD

From a single image to moving hair.

Hair cards, generated together and connected to spring bones.

01

One card, one token

A compact token represents each card’s geometry, root position, and orientation.

02

Generate the set together

A set diffusion transformer denoises all card tokens jointly, conditioned on an image or a point cloud.

03

Make it move

A second transformer generates spring-bone chains. Geometric skinning binds the cards to them.
